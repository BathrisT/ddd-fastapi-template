# rules — правила, на которые ссылается CLAUDE.md

Сюда выносится правило, которое не помещается в CLAUDE.md целиком: тот читается
при каждом запуске и обязан оставаться коротким, иначе его перестанут читать
внимательно.

В CLAUDE.md от такого правила остаётся сжатая выжимка и ссылка сюда. Расходиться
им нельзя: правится текст здесь — правится и выжимка.

Правило кладут сюда, когда оно **переносимое**, то есть про класс задач, а не
про эту предметную область. `композиция-и-скоупы.md` — про приложения с
несколькими входами вообще, а не про конкретный проект; поэтому оно и уезжает в
следующий проект вместе с шаблоном.

Одноразовое решение по одной задаче сюда не идёт: ему место в
`../tasks/<задача>/README.md`.
